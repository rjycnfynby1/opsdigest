# OpsDigest

OpsDigest собирает рабочие обсуждения из Telegram и помогает быстро понять, что произошло, какие задачи требуют внимания и где искать исходные сообщения. Программа запускается локально на Windows и предоставляет веб-интерфейс.

## Возможности

- Сводки по чатам, упоминаниям, задачам и инцидентам.
- Поиск и вопросы по истории сообщений с ссылками на источники.
- Настраиваемые источники, словарь терминов, экспорт и расписание.
- Локальное хранение данных и инструменты защиты приватной информации.

## Экспериментальные функции

- RPA для чтения данных и выполнения операций в ITSM-порталах: поведение зависит от конкретного портала и требует настройки и проверки на тестовом контуре.
- Голосовой ввод и встроенный браузер: поддерживаются не во всех конфигурациях и могут требовать дополнительной настройки.

Эти функции находятся в бета-стадии; проверяйте результат перед использованием в рабочем процессе.

## Запуск

На Windows запустите `OpsDigest.bat` из папки программы. Скрипт подготовит окружение и откроет веб-интерфейс.

Для разработческого запуска установите зависимости из `requirements.txt` и выполните `python -m opsdigest`.

Не добавляйте в репозиторий рабочие выгрузки, учётные данные, Telegram-сессии или конфигурацию с личными данными.
