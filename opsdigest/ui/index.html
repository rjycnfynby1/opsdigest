OpsDigest
Пароль верный. Чтобы открыть переписку и отчёты, войдите в Telegram (шаг «Вход») — без входа в учётку, под которой включали защиту, данные не показываются.

Выгрузки RPA

Задания выполняются последовательно. При ошибке очередь останавливается. Войдите в портал в открывшемся браузере заранее.

Задание: выгрузка инцидентов

Для инцидентов задайте номер либо дату «после». Граница «до» необязательна. Время передаётся в портал без преобразования часового пояса; если портал его изменит, поиск будет отменён.

Задание: выгрузка проблем

Выгружается вся очередь проблем. Это отдельное задание: его можно запускать самостоятельно или вместе с заданиями инцидентов, меняя порядок в списке ниже.

    Изображения
    
    
    Модель читает картинки из переписки — скриншоты ошибок, графики, таблицы, фото документов. Новые изображения
    обязательно описываются перед каждой сводкой; остальные — по кнопке у чата или когда модель решит, что картинка важна для
    ответа на вопрос. Описание сохраняется рядом с картинкой (папка media) и повторно не делается.
    
    
    
    
    
      
    
      
    
    
    
    
    
      
      
      
    Как узнать точный формат: откройте веб-версию Maverick в браузере, нажмите F12 → вкладка «Сеть» (Network),
      отправьте сообщение с картинкой и найдите запрос — во вкладке «Полезная нагрузка» (Payload) видно, как передаётся файл.
      Перенесите сюда эту структуру, заменив текст на {{prompt}}, содержимое файла — на {{image_base64}} (или {{image_data_url}}),
      имя — на {{image_name}}, тип — на {{image_mime}}. Ключ и сам файл сюда не копируйте.

    Прокси
    
    
    По одной ссылке в строке. Пробуются по очереди; если связь через один оборвётся — программа переключится на следующий.

    Выход в интернет для WEB-прокси
      
    WEB-прокси работает через обычный HTTPS. «auto» — как браузер: через прокси Windows, если он настроен; «off» — напрямую; или адрес корпоративного прокси: http://адрес:порт (с логином: http://логин:пароль@адрес:порт).

    Выгрузка всей истории
    
    
    Через Telegram забирается переписка всех чатов, кроме исключённых, — с изображениями и лёгкими файлами (логи, документы).
    Тяжёлые файлы (видео, голосовые, крупные документы) остаются ссылкой — их можно докачать, если понадобятся.
    Выгрузку можно остановить и запустить снова — продолжит с того места, где остановилась. Изображения при выгрузке не описываются
    (это долго): новые описываются перед сводкой, остальные — у чата («Настроить» → «Изображения») или когда модель
    решит, что картинка важна для ответа.

    Источники через Maverick
    
  
    Почта, ITSM (инциденты, проблемы, изменения), вики (Confluence), мессенджер X5 Rooms, трекер задач xTracker
  и расшифровки встреч Scriber AI — через плагины корпоративного агента Maverick.
  Плагины подключаются в чате Maverick; бывает, что подключение «забывается» (истёк вход, нужно заново дать согласие).
  Перед каждым обращением программа проверяет, что плагин отвечает, и если нет — показывает предупреждение (часто со ссылкой
  для входа) и не строит выводов на пустом ответе. Переподключаете плагин вы сами в чате Maverick — логины и пароли
  программа в Maverick не передаёт.

  обмена очищается через 30 секунд. Программа сама никуда их не отправляет: копируете и вставляете в чат Maverick вы.

    В каждом запросе к модели — свои случайные коды: один и тот же человек в соседних запросах под разными
    номерами, поэтому по журналам модели не сшить, кто есть кто. Карта кодов живёт только в памяти на время запроса.

    Глоссарий и база знаний
    
  
    Термины вашей работы: сервисы, приложения и модули, команды, API, процессы, типы заявок и их номера,
  сокращения, типовые проблемы и решения. У термина может быть несколько значений — с признаками, как их различать
  («инцидент» — обращение в ITSM или чат малой аварии). Глоссарий подставляется в каждый запрос к модели: сводки, ИИ в чате,
  вопросы, ИИ-описания. Пополняется сам — при каждой сводке и кнопкой «Пополнить из чатов»; неясное — вопросы вам.
    
  
    
  
    
    
    
      
    Правила и поправки 
    
      
    Чему вы научили программу — как SKILL.md в Claude Code: «номер INC1234567 — обращение в ITSM, чат с INC в
        названии — инцидент-чат», «в сводке не пиши про болталку», «ищи проблемы в заданной группе». Правило попадает в запрос к
        модели, когда оно к нему относится: по области (сводка, ассистент, поиск, описания…) и словам-признакам (без признаков — всегда).
        Пополняется само из ваших отзывов (👍/👎 у любого ответа и отчёта) и указаний в ассистенте («запомни, что…»).

    Голосовой ввод
    
  
    Диктуйте вместо набора: кнопка 🎤 у полей ввода (ассистент, мессенджер, отзывы, правила) или клавиша F9
  в любом поле — говорите, текст появится на месте курсора. Распознаёт локальная модель GigaAM v3 (SberDevices, MIT) — прямо в
  OpsDigest, без серверов и интернета: звук не покидает компьютер и на диск не пишется. Модель сама ставит знаки препинания;
  «новая строка» и «новый абзац» — переносы. Английские термины глоссария (синонимы кириллицей: «Мэверик» → Maverick) пишутся правильно.

    Задачи
    
    
    Долгие задачи программа доводит до конца сама: после перезапуска (сбой, сон компьютера,
      обновление, «Выход» и новый запуск) и после ошибок (нет связи, модель не ответила — повтор через 1, 2, 5… 30 минут).
      Сделанное раньше не повторяется. Закончить задачу раньше — «Остановить».
    
    
    
    
    
    
    
    
    
    
    
    
    
    
    Программа запущена без сторожа (не через OpsDigest.bat) — после сбоя
      она не поднимется сама. Запускайте OpsDigest.bat.
    
  
    

    

    
  
    
    
    Обновление OpsDigest
    
    
    
    
    
      
    
    
    Настройки, переписка и отчёты в рабочей папке не меняются. Старые файлы программы сохраняются —
      если новая версия не запустится за 3 минуты, вернётся прежняя. После перезапуска введите пароль, если включена защита.
    
    
    
    
    
    
    
      
    Доступ к GitHub
    
      
    Репозиторий закрытый, поэтому программе нужен токен только на чтение:
        github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token;
        Resource owner — владелец репозитория (организация); Repository access — Only select repositories →
        репозиторий программы; Permissions → Contents: Read-only. У каждого — свой токен: чужим не пользуйтесь.
        Токен хранится в настройках рабочей папки (зашифрован вместе с ними).
    
      
    
    
    
    
    
    
    Если GitHub из программы недоступен
    
    
    Откройте репозиторий в браузере → Code → Download ZIP и укажите скачанный архив.

    Защита данных
    
    
    Придумайте пароль для запуска программы и короткий ПИН для разблокировки после
    перерыва. Переписка, файлы и отчёты в рабочей папке будут зашифрованы — в Проводнике их не открыть.
    
    
    
    
    
    
    
    
    
    Пароль откроет переписку, только если в программе выполнен вход в вашу учётку Telegram.
    На компьютере, где Telegram из программы пока не подключается (данные — из экспорта), снимите галочку — иначе
    данные не откроются. Потом снять условие можно только после входа в Telegram или кодом восстановления.
    
    
    
    
    
  
    
  
    
    
    Код восстановления
    
    
    Запишите код и храните отдельно от ноутбука (например, дома). Он нужен, если
    забудете пароль. Без пароля и без кода данные не открыть никому — даже вам.
